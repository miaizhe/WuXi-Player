# Via Music Player

一个专为 Via 浏览器设计的简约、强大的音乐播放器脚本。

## 功能特点

- **Shadow DOM 隔离**：使用 Shadow DOM 技术，彻底杜绝脚本样式与网页原生样式的冲突，解决布局重叠问题。
- **智能歌词系统**：
    - 支持双语歌词（翻译歌词）自动换行显示。
    - 精准的高亮进度同步，即使是多行歌词也能顺滑过渡。
    - **歌词编辑模式**：支持鼠标/触摸拖拽歌词位置，并可实时调节字号大小，适配不同网页布局。
- **高度可定制化**：
    - **播放控制**：支持 0.5x - 2.0x 倍速调节，支持单曲/全部循环。
    - **视觉设置**：可自定义歌词颜色、高亮颜色以及背景透明度。
    - **设置持久化**：所有个性化设置均自动保存至本地，下次打开依然生效。
- **音频律动频谱**：内置音频分析器，提供美观的实时律动频谱动画。视觉效果经过精简优化，采用纯色渲染，与高亮色保持一致。
- **自动折叠交互**：
    - 1.5秒无操作自动隐藏到侧边，保持页面整洁。
    - 智能感知鼠标悬停，防止在操作面板时意外隐藏。
    - **切歌静默模式**：切换下一首歌时，播放器保持当前状态（若已折叠则不弹出），减少视觉干扰。
- **精准进度条**：内嵌式进度条设计，支持点击与触摸跳转，完美适配圆角边框。

## 使用方法

1. 打开 Via 浏览器。
2. 进入 `设置` -> `脚本` -> `添加脚本`。
3. 将 `Player.js` 的内容复制粘贴进去。
4. 匹配域名建议填写 `*` 或 `https://*/*`。

## 自定义配置

你可以在脚本顶部的 `config` 对象中修改歌单 ID 或平台：

```javascript
const config = {
    server: 'netease', // 平台: netease, tencent, kino, xiami, baidu
    type: 'playlist',  // 类型: playlist, song, album, search, artist
    id: '10046455237', // 歌单/歌曲 ID
    // ...
};
```

## 本地开发

1. 克隆或下载本项目。
2. 运行 `npm install`。
3. 运行 `npm run serve` 启动本地测试服务器。
4. 访问 `http://localhost:3000` 预览效果。
